## Your tasks
### Add a link
Turn the word "here" into a link that points to `https://example.com`.

```
<a href="https://example.com">here</a>
```

### Add an image
Show an image with helpful alt text for screen readers.

```
<img src="cat.jpg" alt="A gray cat sleeping on a windowsill">
```
