# Introduction to HTML

HTML (HyperText Markup Language) structures the content of a web page. Every element is written as a tag, usually in an opening/closing pair like `<p>...</p>`, and browsers use these tags to know what each piece of content is — a heading, a paragraph, a list, an image, and so on.

## Display
### HTML

```
<h1>Welcome</h1>
<p>This is a paragraph of text.</p>
```
